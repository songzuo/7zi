## 场景一：个人创作者

### 用户画像

- 年龄：25-40 岁
- 职业：自媒体、独立开发者、自由职业者
- 收入：¥5k-30k/月
- 痛点：时间有限，需要多角色协作

### 核心痛点

**1. 精力分散，效率低下**

你的一天可能是这样的：
```
08:00 - 10:00  写代码
10:00 - 12:00  画设计图
14:00 - 16:00  写文案
16:00 - 18:00  社交媒体运营
19:00 - 22:00  学习新技术
```

**你是全能，但不是高效的全能。**

**2. 质量难以保证**

- 代码写得还可以，但架构不优雅
- 设计做得还行，但缺乏专业感
- 文案写得出，但 SEO 效果一般

**你什么都能做，但什么都做不精。**

**3. 时间成本高**

为了完成一个视频，你可能需要：
- 写脚本：2 小时
- 找素材：3 小时
- 剪辑：4 小时
- 加字幕：1 小时
**总计：10 小时**

而一个专业团队协作可能只需要 4 小时。

## 场景二：初创团队

### 用户画像

- 年龄：28-45 岁
- 职业：创业者、CTO、产品经理
- 团队规模：3-10 人
- 痛点：人力预算有限，需要快速迭代

### 核心痛点

**1. 人力成本高**

一个 5 人创业团队需要：
- 产品经理：¥15k/月
- 前端开发：¥20k/月
- 后端开发：¥25k/月
- UI 设计：¥15k/月
- 运营：¥12k/月
**总计：¥87k/月**

**但初创团队预算只有 ¥30k/月。**

**2. 技能不完整**

小团队往往缺乏：
- 专业的 SEO 人员
- 经验丰富的架构师
- 细致的测试工程师
- 成熟的运营团队

**不是不想，是雇不起。**

**3. 开发周期长**

"再给我一个月，这个功能就能上线。"

但在创业中，时间就是生命。慢一周，可能就被竞品抢先。

## 场景三：企业研发部门

### 用户画像

- 年龄：30-50 岁
- 职业：技术总监、研发经理、架构师
- 公司规模：50-500 人
- 痛点：开发任务积压，测试资源不足，文档维护困难

### 核心痛点

**1. 开发任务积压**

业务方提出的需求：
- 新功能开发
- Bug 修复
- 技术债务清理
- 性能优化
- 安全加固

但开发人员有限，任务永远做不完。

**2. 测试资源不足**

"这个功能什么时候能测试完成？"

测试人员往往是团队的瓶颈：
- 测试用例编写慢
- 回归测试耗时长
- Bug 定位需要时间

**3. 文档维护困难**

"这个 API 文档还是去年的。"

文档是大家都认为重要，但都没时间做的事：
- API 文档不更新
- 系统架构图过时
- 新人培训成本高

---

## 不适用场景

7zi 也很强大，但不是万能的。以下场景可能不适用：

### ❌ 不适用于

**1. 超高精度需求**
- 医疗诊断
- 金融交易
- 法律判决
- *AI 输出仍需人工审核*

**2. 物理操作**
- 硬件组装
- 现场施工
- 设备维修
- *AI 无法操作物理世界*

**3. 需要法律责任的场景**
- 签署合同
- 财务审批
- 法务咨询
- *AI 不承担法律责任*

### ✅ 适用于

- 内容创作（文案、文档、视频）
- 开发辅助（代码生成、测试、文档）
- 设计工作（UI、配图、品牌）
- 数据分析（调研、洞察、报告）
- 营销推广（SEO、社交媒体、广告）
- 客服支持（问答、工单）

## ROI 分析

### 7zi 的价值公式

```
价值 = 时间节省 × 人力成本 + 质量提升 × 转化率 - 学习成本
```

### 个人创作者

```
时间节省：每天 4 小时 × ¥300/小时 = ¥1,200/天
质量提升：内容质量提升 → 订阅数增加 2 倍 → 收入 ¥5k/月
学习成本：2 小时

月度 ROI：
¥1,200 × 22 天 + ¥5,000 - ¥300 = ¥31,100
```

### 初创团队

```
人力节省：¥87k - ¥75k = ¥12k/月
开发加速：30 天 → 7 天 = 提前 23 天上线
假设每月利润 ¥100k
23 天提前 = ¥76.6k 额外收入

月度 ROI：
¥12k + ¥76.6k - ¥200 = ¥88.4k
```

### 企业研发

```
效率提升：3 倍开发效率 = 相当于增加 2 倍人力
人力节省：¥100k × 2 = ¥200k/月
质量提升：Bug 减少 50% → 维护成本降低 ¥30k/月

月度 ROI：
¥200k + ¥30k - ¥500 = ¥229.5k
```
