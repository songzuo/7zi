## 第 0 分钟：准备

### 访问官网

打开浏览器，访问 [https://7zi.studio](https://7zi.studio)

### 了解 7zi 能做什么

在开始之前，先了解 7zi 的核心能力：

- **📝 内容创作**：文案、博客、营销文案
- **💻 开发任务**：代码编写、Bug 修复、架构设计
- **🎨 设计工作**：UI 设计、配图、品牌视觉
- **📊 数据分析**：市场调研、竞品分析、数据洞察
- **📣 营销推广**：SEO 优化、社交媒体内容、广告文案
- **🛠️ 运维部署**：服务器配置、CI/CD、监控告警

**7zi 的 11 位 AI 成员覆盖了企业运营的方方面面。**

## 第 1 分钟：创建任务

### 打开任务面板

点击主页的 "创建新任务" 按钮，进入任务创建界面。

### 描述你的需求

在任务描述框中，用自然语言描述你的需求。

**示例 1：内容创作**
```
帮我写一篇关于"AI 团队"的博客文章，重点突出与传统 AI 工具的区别。
```

**示例 2：开发任务**
```
帮我创建一个响应式登录页面，包含邮箱和密码输入框。
```

**示例 3：营销文案**
```
为 7zi 产品写一条 Twitter 推广文案，吸引初创团队关注。
```

### 选择 AI 成员（可选）

默认情况下，主管 AI 会自动分析任务并分配给最合适的成员。

你也可以手动选择：
- 📺 媒体：内容创作
- ⚡ Executor：代码编写
- 📣 推广专员：营销文案
- 🎨 设计师：设计任务

**新手建议：让系统自动分配，体验智能任务调度。**

## 进阶技巧

### 批量任务

你可以一次性提交多个任务，AI 团队会并行处理：

```
任务 1: 写产品介绍
任务 2: 设计 logo 配色
任务 3: 分析竞品定价

→ 同时执行，节省时间
```

### 模板复用

常用的任务可以保存为模板：

```
模板："周报生成"
包含：
- 📺 媒体：撰写周报内容
- 📣 推广专员：提取关键数据
- 💰 财务：成本分析

每次使用只需填入本周工作内容
```

### 定时任务

设置定时任务，让 AI 团队在固定时间工作：

```
定时任务：每周一早上 9 点生成上周数据报告
→ 每周一早上自动完成，无需手动触发
```

## 常见问题

### Q: 需要技术背景吗？
**A: 不需要。** 7zi 的设计理念就是"零代码"，你只需要用自然语言描述需求即可。

### Q: AI 成员会互相理解吗？
**A: 会。** 主管 AI 会自动协调成员间的协作，确保上下文共享。

### Q: 可以自己定义 AI 角色吗？
**A: 目前 11 位角色已覆盖主要需求，未来将开放自定义角色功能。

### Q: 数据安全吗？
**A: 7zi 开源核心代码，你可以自行部署，数据完全可控。云端托管版本也采用企业级加密。
