## 📝 Report Guidelines

### Creating New Reports

When creating new reports:

1. **Use descriptive filenames**
   - Format: `TYPE-REPORT-DATE.md` (e.g., `OPTIMIZATION-REPORT-2026-03-18.md`)
   - Use kebab-case
   - Include date for version control

2. **Include metadata header**
   ```markdown
   # Report Title

   **Date**: YYYY-MM-DD
   **Author**: Your Name
   **Type**: Bug Report | Optimization | Audit | Summary
   **Priority**: High | Medium | Low
   **Status**: Draft | In Progress | Complete

   ---
   ```

3. **Structure your report**
   - Executive Summary
   - Details/Analysis
   - Recommendations
   - Action Items
   - Appendices (if needed)

4. **Use Markdown formatting**
   - Headers (##, ###)
   - Lists (bullets, numbered)
   - Code blocks (with syntax highlighting)
   - Tables for structured data
   - Bold/Italic for emphasis

### Updating Existing Reports

- Add update notes at the top
- Use strike-through for obsolete information
- Update the "Last Updated" date
- Archive old versions if necessary
