## 🔍 一、用户流程问题分析

### 1.1 注册流程 — ❌ 严重问题

**现状**:
- 登录页面 (`/login`) 存在，但**注册页面不存在**
- 登录页底部有"立即注册"链接指向 `/register`，但该页面返回 404
- 用户点击注册后得到 404 错误，**直接流失**

**代码证据**:
```tsx
// /7zi-frontend/src/app/[locale]/login/page.tsx
<p className="text-gray-600 dark:text-gray-400">
  还没有账户？{' '}
  <a href="/register" className="text-blue-600 hover:text-blue-700...">
    立即注册
  </a>
</p>
```

**影响**:
- 新用户 100% 流失在注册第一步
- 品牌形象受损（死链 = 不专业）
- 所有后续转化无从谈起

**流失率预估**: ~100% (新用户)

---

### 1.2 定价页面流程 — ⚠️ 部分功能缺失

**现状**:
- 定价页面 `/pricing` 设计完整，有 Free/Pro/Enterprise 三层定价
- 邮件收集表单存在，但**后端 API 未集成**（TODO 注释）
- Pro 版本"立即升级"按钮无实际功能
- Enterprise 版本"联系销售"无实际功能

**代码证据**:
```tsx
// /7zi-frontend/src/app/pricing/page.tsx
const handleSubmit = async (e: React.FormEvent) => {
  e.preventDefault()
  if (!email) return
  try {
    // TODO: Integrate with backend API  ← 未实现
    console.log('Email submitted:', email)
    setSubmitStatus('success')
  } catch (error) {
    console.error('Error submitting email:', error)
    setSubmitStatus('error')
  }
}
```

**问题**:
1. 升级按钮无任何操作（无 Modal、无页面跳转、无表单）
2. 邮件表单后端未集成，无法收集销售线索
3. 用户无法完成从"感兴趣"到"留下联系方式"的转化

**流失率预估**: ~95%（定价页访客）

---

### 1.3 支付/下单流程 — ❌ 完全缺失

**现状**:
- 无购物车功能
- 无下单确认页面
- 无支付网关集成（Stripe/Alipay/微信支付等）
- 无订阅管理页面

**影响**:
- 即使用户想付费，也无法完成支付
- B2B 销售（Enterprise）无报价/合同流程
- 所有定价策略无法产生实际收入

---

### 1.4 客服响应流程 — ⚠️ 仅被动反馈

**现状**:
- 有 Feedback 页面 (`/feedback`) 供用户提交反馈
- 无实时在线客服（Chat/WhatsApp/邮件）
- 无 FAQ 页面（定价页有 FAQ 是好实践）
- 无工单系统

**问题**:
- 用户有疑问时无处咨询 → 离开
- 反馈提交后无确认邮件通知
- 无满意度回访机制

## 📈 二、转化优化建议

### P0 — 立即修复（阻断型）

#### 🔴 建议 1: 创建注册页面（高优先级）

**问题**: 新用户无法注册，100% 流失

**解决方案**:
1. 创建 `/register` 页面（支持 `[locale]/register`）
2. 实现邮箱注册 + 验证码流程
3. 或集成第三方 Auth（Google/GitHub/微信）

**最小可行方案**:
```tsx
// 至少实现一个最简单的注册页
// /app/[locale]/register/page.tsx
- 邮箱输入
- 密码输入 + 确认
- 验证码（可选）
- 注册按钮 → 调用 POST /api/auth/register
```

**预期效果**: 打开新用户注册通道，预计注册转化率 0% → 15-25%

---

#### 🔴 建议 2: 集成定价页邮件收集（高优先级）

**问题**: 有意向客户无法留下联系方式

**解决方案**:
1. 实现 `/api/leads` POST 接口
2. 表单提交改为调用 API（目前只有 TODO）
3. 提交后显示"我们的销售团队将在 24 小时内联系您"

**预期效果**: 收集销售线索，预计转化率 5-10% 的访客留下联系方式

---

### P1 — 短期优化（重要）

#### 🟡 建议 3: 添加升级引导流程

**问题**: Pro 升级按钮无效

**解决方案**:
1. 点击"立即升级" → 弹出订阅选择 Modal
2. 选择后跳转 Stripe Checkout（或显示联系销售表单）
3. 至少实现一个可用的支付流程（哪怕是演示）

**实现选项**:
- **简易版**: 显示"功能开发中，请联系 sales@7zi.com"
- **中级版**: Stripe Checkout 集成（支持信用卡）
- **完整版**: 完整订阅管理 Portal

---

#### 🟡 建议 4: 实现用户引导（Onboarding）

**问题**: 用户注册后不知如何使用

**解决方案**:
1. 注册成功后弹出引导 Modal（3-4 步）
2. Dashboard 添加"快速开始"卡片
3. 提供示例工作流模板

**预期效果**: 提升用户激活率，预计 7 日留存提升 20-30%

---

#### 🟡 建议 5: 添加实时客服入口

**问题**: 用户有疑问时无法获得帮助

**解决方案**:
1. 右下角添加"在线咨询"按钮
2. 接入 WhatsApp Business / Tawk.to / Intercom
3. 或至少添加 FAQ 页面

**预期效果**: 减少因疑问流失的客户，预计减少 10-15% 流失

---

### P2 — 中期优化（增强型）

#### 🟢 建议 6: 完整支付流程

**问题**: 无法实际收费

**解决方案**:
1. Stripe 集成（国际支付）
2. 支付宝/微信支付集成（中国市场）
3. 订阅管理 Portal（查看/取消订阅）

**预期效果**: 开通付费通道，实现营收

---

#### 🟢 建议 7: 转化漏斗数据追踪

**问题**: 无法衡量各环节转化率

**解决方案**:
1. 添加 Google Analytics / Plausible 追踪
2. 埋点：注册、定价页访问、CTA 点击、表单提交
3. 统计各环节转化率，识别最大流失点

**预期效果**: 数据驱动优化，有针对性地提升转化率

---

#### 🟢 建议 8: 挽回流失用户

**问题**: 用户离开后不会回来

**解决方案**:
1. 退出意图弹窗（即将离开时显示优惠）
2. 邮件召回（未完成注册/订阅的用户）
3. 废弃购物车提醒（如有购买意向但未付款）
