## 📊 项目概况

### 技术栈现状

- **前端框架**: Next.js 16.2.1 + React 19.2.4
- **UI库**: Tailwind CSS 4
- **状态管理**: Zustand 5.0.12
- **实时通信**: Socket.IO Client 4.8.3
- **测试框架**: Vitest 4.0.18 + Playwright 1.58.2
- **数据库**: better-sqlite3 11.5.0
- **认证**: jose 6.2.1 (JWT)
- **监控**: Sentry 10.44.0
