**核心功能:**
- ✅ 多字段组合搜索（AND、OR、NOT）

## 🔄 升级指南

### 从 v1.12.x 升级到 v1.13.0

**前置要求:**
- Node.js 18+
- PostgreSQL 15+
- Redis 7+

**升级步骤:**

1. **备份数据库**
   ```bash
   pg_dump -U your_user your_database > backup_v112.sql
   ```

2. **更新依赖**
   ```bash
   npm install
   ```

3. **运行数据库迁移**
   ```bash
   npm run migrate
   ```

4. **重新构建**
   ```bash
   npm run build
   ```

5. **重启服务**
   ```bash
   npm run start
   ```

**注意事项:**
- 升级过程中会短暂中断服务（预计 5-10 分钟）
- 建议在低峰期执行升级
- 升级前请确保数据库备份完整
