## 🔧 技术细节

### Store 架构特性

**1. 类型安全**
- 完整的 TypeScript 类型定义
- 导出所有接口和类型
- 便于组件中使用类型推断

**2. 持久化策略**
- Auth Store: 持久化用户信息和 token
- App Store: 持久化所有设置
- Notification/WebSocket: 内存存储（不需要持久化）

**3. 性能优化**
- 提供选择器函数避免不必要重渲染
- 使用 partialize 减小持久化数据量
- WebSocket 限制消息队列（100 条）

**4. 开发体验**
- 统一导出入口 (`@/stores`)
- 快捷方法 (notification store 的 success/error 等)
- 完整的错误处理
