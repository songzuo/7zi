## 品牌统一规范

### 视觉规范

#### Logo 使用

```
✅ 正确使用：
- 官方渠道主 Logo
- 适当缩放，保持清晰
- 与背景颜色协调
- 留有足够的呼吸空间

❌ 错误使用：
- 修改 Logo 颜色
- 拉伸或变形
- 模糊不清
- 与背景冲突
```

#### 配色方案

```
主色：Cyan (#06b6d4)
  - 用于：CTA 按钮、链接、强调元素

辅助色：Purple (#8b5cf6)
  - 用于：渐变、装饰、次要强调

中性色：
  - 文字：Zinc-900 (#18181b) / Zinc-400 (#a1a1aa)
  - 背景：White (#ffffff) / Zinc-50 (#fafafa)
  - 边框：Zinc-200 (#e4e4e7) / Zinc-800 (#27272a)
```

#### 字体规范

```
中文：
- 标题：苹方、思源黑体
- 正文：苹方、思源黑体

英文：
- 标题：Inter, Helvetica, Arial
- 正文：Inter, Helvetica, Arial

代码：
- 等宽字体：JetBrains Mono, Fira Code
```

### 内容规范

#### 标题格式

```
Twitter/X:
  - 限制 280 字
  - 表情符号使用：🤖 💡 🚀
  - Hashtag：#7zi #AITeam #AIAgents

微博：
  - 限制 140 字
  - 表情符号：🤖 💡 🚀 📣
  - 话题标签：#7zi智能体 #AI团队

B站/YouTube：
  - 标题清晰吸引人
  - 时长标注
  - 封面图配合

知乎/掘金：
  - 标题专业、有吸引力
  - 副标题补充说明
  - 标签准确
```

#### 文案风格

```
语调：
  - 专业但不刻板
  - 友好但不随意
  - 有价值但不说教

结构：
  - 开头：抓住注意力
  - 中间：提供价值
  - 结尾：行动号召（CTA）

避免：
  - 过度营销
  - 模糊不清
  - 错误信息
  - 低质量内容
```

## 附录

### A. 账号创建清单

#### Twitter/X 创建步骤

1. 访问 https://twitter.com/signup
2. 使用团队邮箱注册
3. 完成邮箱验证
4. 配置个人资料（Logo、简介、链接）
5. 设置封面图
6. 发布第一条 Tweet
7. 启用双因素认证

#### 微博创建步骤

1. 访问 https://weibo.com/signup
2. 使用企业邮箱注册
3. 实名认证（身份证）
4. 蓝V认证（企业认证）
5. 配置账号信息
6. 发布第一条微博
7. 设置话题标签

#### B站创建步骤

1. 访问 https://passport.bilibili.com/register
2. 注册账号
3. 实名认证
4. 认证个人/机构
5. 上传 Logo 和背景图
6. 完善个人简介
7. 发布第一个视频

#### YouTube 创建步骤

1. 使用 Google 账号登录
2. 访问 https://www.youtube.com/create_channel
3. 创建频道
4. 配置频道信息
5. 上传频道艺术
6. 上传第一个视频
7. 优化频道 SEO
