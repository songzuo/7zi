## 流程概述

### 流程图

```
内容策划 → 内容创作 → 内容审核 → 内容发布 → 数据追踪 → 优化迭代
    ↑                                                        ↓
    └────────────────────── 数据反馈 ──────────────────────┘
```

### 关键节点

| 阶段         | 负责人      | 时间要求 | 输出              |
| ------------ | ----------- | -------- | ----------------- |
| **内容策划** | 📺 媒体     | 每周一次 | 内容日历          |
| **内容创作** | AI 团队     | 按需     | 初稿内容          |
| **内容审核** | 主管        | 发布前   | 审核通过/修改意见 |
| **内容发布** | 📣 推广专员 | 按计划   | 已发布内容        |
| **数据追踪** | 📣 推广专员 | 每周一次 | 数据报告          |
| **优化迭代** | 📺 媒体     | 每月一次 | 优化方案          |

### SLA (Service Level Agreement)

| 任务类型     | 正常处理时间 | 紧急处理时间 | 备注                  |
| ------------ | ------------ | ------------ | --------------------- |
| 内容策划     | 1-2 天       | 4 小时       | 每周一次              |
| 博客文章创作 | 1-2 天       | 4 小时       | 标准长度 2000-3000 字 |
| 视频制作     | 3-5 天       | 1 天         | 5-10 分钟视频         |
| 社交媒体内容 | 1-2 小时     | 30 分钟      | 短内容                |
| 内容审核     | 4 小时       | 1 小时       | 发布前完成            |
| 紧急发布     | 1 小时       | 30 分钟      | 需要特殊审批          |

## 内容策划流程

### 每周内容策划会议

**时间**: 每周一 10:00
**时长**: 30-60 分钟
**参与者**: 主管、📺 媒体、📣 推广专员、相关子代理

#### 会议议程

1. **回顾上周表现** (10 分钟)
   - 数据报告
   - 亮点与不足
   - 用户反馈

2. **本周重点主题** (15 分钟)
   - 产品更新
   - 行业热点
   - 用户需求

3. **内容分配** (20 分钟)
   - 博客选题
   - 社交媒体计划
   - 视频制作安排

4. **协调与确认** (15 分钟)
   - 时间节点确认
   - 资源分配
   - 责任人确认

## 内容创作流程

### 博客文章创作

#### 1. 选题与大纲 (30 分钟)

**输入**: 内容日历
**输出**: 文章大纲

```
步骤：
1. 确定文章主题
2. 搜索相关资料
3. 制定文章结构
4. 明确核心观点
5. 规划配图需求
```

**检查点**:

- [ ] 主题明确
- [ ] 结构合理
- [ ] 观点清晰
- [ ] 符合品牌调性

#### 2. 初稿创作 (1-2 小时)

**输入**: 文章大纲
**输出**: 文章初稿

```
步骤：
1. 撰写前言（100-200 字）
2. 撰写正文（2000-3000 字）
3. 撰写总结（100-200 字）
4. 添加引用链接
5. 插入代码示例（如需要）
```

**文章结构模板**:

```markdown
# [吸睛标题]

> 一句话总结文章价值

## 前言 (100-200 字)

简述背景、痛点、本文价值

## 核心内容 (2000-3000 字)

### 小标题 1

内容...

### 小标题 2

内容...

## 案例分析 (可选)

真实案例展示

## 总结 (100-200 字)

总结核心观点，行动建议

## 延伸阅读

相关文章链接

## 关于 7zi

简短介绍，引导关注
```

#### 3. SEO 优化 (30 分钟)

**输入**: 文章初稿
**输出**: 优化后的文章

```
步骤：
1. 标题优化（包含核心关键词）
2. 段落优化（增加小标题）
3. 内部链接（相关文章）
4. 图片 Alt 标签
5. Meta 描述（155 字）
6. URL slug 优化
```

**SEO 检查清单**:

- [ ] 标题包含主关键词
- [ ] Meta 描述清晰
- [ ] URL slug 简洁
- [ ] H1-H6 层级正确
- [ ] 内部链接相关
- [ ] 图片 Alt 标签完整
- [ ] 文章长度 > 1000 字

#### 4. 配图制作 (1-2 小时)

**输入**: 文章内容
**输出**: 配图文件

```
配图需求：
- 封面图 (1200x630px)
- 内容配图 (2-3 张)
- 社交媒体分享图 (1200x630px)
- 文章内插图 (适合尺寸)
```

#### 5. 格式调整 (30 分钟)

**输入**: 文章内容 + 配图
**输出**: Markdown 文件

```
步骤：
1. 检查 Markdown 格式
2. 确保代码高亮正确
3. 调整图片位置
4. 检查错别字
5. 确保链接有效
```

### 视频内容创作

#### 1. 脚本撰写 (1-2 小时)

**输入**: 视频主题
**输出**: 视频脚本

```
脚本模板：
# 视频标题
# 时长：X 分钟
# 目标：XXX

## 开头 (30 秒)
- 吸引注意力
- 介绍视频内容
- 预告价值

## 正文 (X 分钟)
- 分段讲解
- 配合演示
- 穿插案例

## 结尾 (30 秒)
- 总结要点
- 行动号召
- 订阅提醒
```

#### 2. 录制 (2-4 小时)

**输入**: 视频脚本
**输出**: 录制素材

```
步骤：
1. 屏幕录制（使用 OBS）
2. 旁白录制（使用专业麦克风）
3. 出镜录制（如需要）
4. B-roll 素材采集
```

#### 3. 剪辑 (2-4 小时)

**输入**: 录制素材
**输出**: 成品视频

```
步骤：
1. 素材整理
2. 粗剪（按脚本拼接）
3. 精剪（调整节奏）
4. 加配乐（版权音乐）
5. 加字幕
6. 加片头片尾
7. 导出成品
```

## 内容审核流程

### 审核分级

#### 三级审核制度

| 等级     | 审核内容                       | 审核人      | 时间要求       |
| -------- | ------------------------------ | ----------- | -------------- |
| **一级** | 日常内容（博客、社交媒体）     | 📣 推广专员 | 发布前 2 小时  |
| **二级** | 重要内容（产品更新、行业文章） | 📺 媒体     | 发布前 4 小时  |
| **三级** | 核心内容（品牌声明、重大发布） | 主管 + 主人 | 发布前 24 小时 |

### 审核清单

#### 内容质量检查

```
✅ 基础检查
  - [ ] 无错别字
  - [ ] 语法正确
  - [ ] 标点符号规范
  - [ ] 链接有效

✅ 内容检查
  - [ ] 内容准确
  - [ ] 逻辑清晰
  - [ ] 观点明确
  - [ ] 数据可靠

✅ 品牌检查
  - [ ] 符合品牌调性
  - [ ] Logo 使用正确
  - [ ] 配色符合规范
  - [ ] 语言风格统一

✅ SEO 检查
  - [ ] 标题优化
  - [ ] Meta 描述
  - [ ] 关键词布局
  - [ ] 内部链接

✅ 合规检查
  - [ ] 无敏感内容
  - [ ] 版权合规
  - [ ] 符合平台规则
  - [ ] 法律风险低
```

#### 敏感内容处理

**需要主人批准的内容**:

- [ ] 产品定价调整
- [ ] 重大功能变更
- [ ] 合作伙伴公告
- [ ] 投资融资信息
- [ ] 品牌策略调整
- [ ] 危机公关声明
- [ ] 法律相关内容

**需要主管批准的内容**:

- [ ] 技术架构变更
- [ ] 重要产品更新
- [ ] 行业观点文章
- [ ] 用户案例发布
- [ ] 社区重大公告

### 审核流程

```
内容提交
   ↓
📣 推广专员审核（一级）
   ↓ 通过
📺 媒体审核（二级，如需要）
   ↓ 通过
主管审核（三级，如需要）
   ↓ 通过
主人批准（核心内容，如需要）
   ↓ 通过
发布
```

## 紧急发布流程

### 适用场景

- 产品紧急 Bug 修复通知
- 安全漏洞公告
- 服务中断通知
- 紧急功能发布
- 危机公关声明

### 流程

```
1. 紧急事件发生
   ↓
2. 主人或主管决策是否需要紧急发布
   ↓ （需要）
3. 快速撰写内容（30 分钟）
   ↓
4. 主人或主管快速审核（15 分钟）
   ↓
5. 立即发布（15 分钟）
   ↓
6. 监控反馈并响应
```

| 发布执行 | 15 分钟    | 📣 推广专员 |

## 常见问题与解决方案

### Q1: 内容发布后发现错误怎么办？

**解决方案**:

- 小错误（错别字）：立即修改，无需特别说明
- 重要错误（数据错误）：立即修改 + 发布更正声明
- 严重错误（误导信息）：删除 + 重新发布 + 道歉声明

### Q2: 某篇内容表现不好怎么办？

**解决方案**:

- 分析原因（标题、内容、发布时间）
- 优化后重新发布
- 总结经验，避免重复

### Q3: 如何应对负面评论？

**解决方案**:

- 理性回复，保持专业
- 区分建设性批评和恶意攻击
- 严重情况由主管或主人处理
- 及时归档并总结

### Q4: 内容创意枯竭怎么办？

**解决方案**:

- 参考竞品内容
- 关注行业热点
- 收集用户反馈
- 与团队头脑风暴
- 使用 AI 辅助生成创意

### Q5: 如何平衡质量和数量？

**解决方案**:

- 制定内容优先级
- 高质量内容 > 大量低质量内容
- 定期质量审查
- 用户反馈指导方向
