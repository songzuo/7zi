## 2. 主要改进点

### 2.1 🔴 P0: lib/ 层重复目录清理（必须完成）

**问题描述**：存在 3 组重复目录，导致维护困难和混淆。

| 重复组     | 旧位置                     | 新位置                      | 状态        |
| ---------- | -------------------------- | --------------------------- | ----------- |
| agent 核心 | `src/lib/agent/`           | `src/lib/agents/agent/`     | ⚠️ 重复存在 |
| a2a 协议   | `src/lib/a2a/`             | `src/lib/agents/a2a/`       | ⚠️ 重复存在 |
| scheduler  | `src/lib/agent-scheduler/` | `src/lib/agents/scheduler/` | ⚠️ 重复存在 |

**影响范围**：

- `app/api/a2a/*` 路由（10+ 处导入）
- `agent-dashboard/page.tsx`（2 处导入）
- `TeamStatus.tsx`（2 处导入）

**解决方案**：

```
src/lib/agents/
├── agent/           # 核心 Agent 操作
├── a2a/             # Agent-to-Agent 协议
├── scheduler/       # 调度系统
└── tools/           # 工具函数
```

### 2.2 🟡 P1: 依赖清理和升级

**当前状态**：

- 版本: 1.4.0

**需要关注的依赖**：
