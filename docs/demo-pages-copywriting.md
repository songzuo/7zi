### 核心功能展示

#### 1. 房间系统

**标题**: 多房间协作，隔离无干扰  
**描述**:

```
支持 6 种房间类型：project、task、chat、document、voice、video

三种可见性模式：
• 公开房间 (public) - 任何人可加入
• 私有房间 (private) - 需要邀请加入
• 仅邀请房间 (invite-only) - 严格访问控制

智能配置：
• 最大参与者限制
• 消息历史开关
• 自动清理时间
• 访客权限控制
```

#### 2. 权限控制

**标题**: 16 种权限，5 级角色  
**描述**:

```
角色层级（从高到低）：
👑 Owner - 房间所有者，完全控制
🔧 Admin - 管理员，用户+房间管理
⭐ Moderator - 协调员，消息+用户管理
👤 Member - 成员，完整协作权限
👀 Guest - 访客，只读访问

权限类别：
• 房间权限 (7种) - join/leave/manage/view/invite/kick/ban
• 消息权限 (6种) - send/edit/delete/react/pin/view_history
• 管理权限 (3种) - manage_users/manage_rooms/manage_permissions
```

#### 3. 消息持久化

**标题**: 离线不丢失，历史可追溯  
**描述**:

```
核心能力：
✅ 内存存储 - O(1) 访问速度
✅ 离线队列 - 每用户 100 条，7 天 TTL
✅ 消息操作 - 编辑、删除、反应、置顶
✅ 历史查询 - 时间/用户/类型过滤

适用场景：
• 团队会议纪要自动保存
• 项目讨论历史可查
• 离线成员消息不遗漏
```
