## 1. 项目概览

### 1.1 目标

将现有的工作流系统升级为专业级可视化工作流编排器，提供：

- 基于 React Flow 的拖拽式节点编辑器
- 自定义节点动态注册支持
- 基于 A2A Protocol v2.1 的实时协作
- 完善的版本控制和模板系统

### 1.2 现有基础

| 模块       | 状态        | 说明                         |
| ---------- | ----------- | ---------------------------- |
| 工作流引擎 | ✅ 完成     | `src/lib/workflow/engine.ts` |
| 节点执行器 | ✅ 完成     | 6 种内置执行器               |

**数据库 Schema 设计：**

```prisma
model Workflow {
  id          String         @id @default(cuid())
  name        String
  description String?
  version     Int            @default(1)
  status      WorkflowStatus @default(DRAFT)

  // 工作流数据 (JSON)
  nodes       Json
  edges       Json
  config      Json

  // 关系
  versions    WorkflowVersion[]
  runs        WorkflowRun[]

  createdAt   DateTime       @default(now())
  updatedAt   DateTime       @updatedAt
  createdBy   String
  updatedBy   String

  @@index([status])
  @@index([createdBy])
}

model WorkflowVersion {
  id          String   @id @default(cuid())
  workflowId  String
  workflow    Workflow @relation(fields: [workflowId], references: [id])

  version     Int
  message     String?
  snapshot    Json     // 完整快照

  changes     Json?    // 变更摘要
  createdBy   String
  createdAt   DateTime @default(now())

  @@unique([workflowId, version])
  @@index([workflowId])
}

model WorkflowRun {
  id          String         @id @default(cuid())
  workflowId  String
  workflow    Workflow       @relation(fields: [workflowId], references: [id])

  status      RunStatus      @default(PENDING)
  progress    Json           // 执行进度
  results     Json?          // 节点结果
  outputs     Json?          // 最终输出
  error       Json?

  triggeredBy String
  triggerType String
  startedAt   DateTime       @default(now())
  endedAt     DateTime?
  duration    Int?           // 毫秒

  @@index([workflowId])
  @@index([status])
}
```

**验收标准：**

- [ ] 数据库迁移成功
- [ ] CRUD API 功能完整
