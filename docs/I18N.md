## 概述

7zi Studio 使用 `next-intl` 库实现完整的国际化支持，当前支持：
- 🇨🇳 中文 (zh-CN)
- 🇬🇧 英语 (en-US)

### 核心特性

- ✅ **动态路由** - 使用 `[locale]` 动态段实现多语言 URL
- ✅ **类型安全** - 完整的 TypeScript 类型支持
- ✅ **SEO 友好** - 每种语言独立的元数据和结构化数据
- ✅ **服务端渲染** - 支持服务端和客户端翻译
- ✅ **语言切换** - 无刷新的语言切换功能

## 添加新语言

### 步骤 1: 更新配置

编辑 `src/i18n/config.ts`:

```typescript
export const locales = ['zh-CN', 'en-US', 'ja-JP'] as const;
export type Locale = (typeof locales)[number];

export const defaultLocale: Locale = 'zh-CN';

export const localeNames: Record<Locale, string> = {
  'zh-CN': '简体中文',
  'en-US': 'English',
  'ja-JP': '日本語',
};
```

### 步骤 2: 创建翻译文件

创建 `src/messages/ja-JP.json`:

```json
{
  "nav": {
    "home": "ホーム",
    "about": "について",
    "team": "チーム",
    "contact": "お問い合わせ"
  },
  "home": {
    "hero": {
      "title": "AIで再定義",
      "description": "..."
    }
  }
}
```

### 步骤 3: 更新语言切换组件

语言切换会自动支持新语言。

## 使用翻译

### 在服务端组件中

```typescript
import { getTranslations } from 'next-intl/server';
import { setRequestLocale } from 'next-intl/server';

export default async function Page({ params }: { params: { locale: string } }) {
  const { locale } = params;
  setRequestLocale(locale);
  
  const t = await getTranslations();
  const title = t('home.hero.title');
  
  return <h1>{title}</h1>;
}
```

### 在客户端组件中

```typescript
'use client';

import { useTranslations } from 'next-intl';

export default function MyComponent() {
  const t = useTranslations('home.hero');
  
  return <h1>{t('title')}</h1>;
}
```

### 带命名空间的翻译

```typescript
// 嵌套命名空间
const t = useTranslations('home.services.web.features');
const feature1 = t('0'); // 获取第一个元素
const feature2 = t('1');

// 或者使用 raw 方法获取整个数组
const features = t.raw('web.features') as string[];
```

## SEO 和元数据

### 动态元数据

```typescript
import { getTranslations } from 'next-intl/server';
import type { Metadata } from 'next';

export async function generateMetadata({ params }: { params: { locale: string } }): Promise<Metadata> {
  const { locale } = params;
  const t = await getTranslations({ locale, namespace: 'metadata' });
  
  return {
    title: t('title'),
    description: t('description'),
    openGraph: {
      title: t('ogTitle'),
      description: t('ogDescription'),
      locale: locale === 'zh-CN' ? 'zh_CN' : 'en_US',
    },
  };
}
```

### 结构化数据

```typescript
<StructuredData
  locale={locale}
  schemas={['website', 'organization']}
  customSchemas={[
    {
      '@context': 'https://schema.org',
      '@type': 'WebPage',
      name: t('structuredData.name'),
      description: t('structuredData.description'),
    },
  ]}
/>
```

## 最佳实践

### 1. 命名空间组织

保持翻译文件结构化：

```json
{
  "nav": { /* 导航 */ },
  "footer": { /* 页脚 */ },
  "home": {
    "hero": { /* 首页 Hero */ },
    "services": { /* 服务 */ },
    "team": { /* 团队 */ }
  },
  "about": { /* 关于页面 */ }
}
```

### 2. 翻译键命名规范

- 使用 kebab-case: `page-title`, `hero-description`
- 避免过深的嵌套（最多 3 层）
- 保持键名描述性和一致性

### 3. 占位符和变量

```json
{
  "greeting": "你好，{name}！",
  "items-count": "共 {count} 个项目"
}
```

```typescript
const t = useTranslations('common');
const message = t('greeting', { name: 'John' });
```

### 4. 日期和数字格式化

```typescript
import { useFormatter } from 'next-intl';

export function DateDisplay({ date }: { date: Date }) {
  const format = useFormatter();
  
  return (
    <time dateTime={date.toISOString()}>
      {format.dateTime(date, {
        year: 'numeric',
        month: 'long',
        day: 'numeric',
      })}
    </time>
  );
}
```

### 5. RTL (从右到左) 语言支持

如果需要支持阿拉伯语等 RTL 语言：

```typescript
// next.config.js
module.exports = {
  i18n: {
    locales: ['ar'],
    defaultLocale: 'ar',
    rtl: ['ar'], // RTL 语言列表
  },
};
```

```css
[dir="rtl"] {
  /* RTL 样式覆盖 */
  .text-left { text-align: right; }
}
```

## 常见问题

### Q: 如何添加默认值？

```json
{
  "title": "我的标题 | Default Title"
}
```

### Q: 如何处理复数？

```typescript
import { useTranslations } from 'next-intl';

const t = useTranslations('items');
const message = t('count', { count: items.length });
```

```json
{
  "items": {
    "count_one": "{count} 项",
    "count_other": "{count} 项"
  }
}
```

### Q: 如何切换语言时保持状态？

使用 URL 参数并避免客户端状态：

```typescript
// 不要这样做
const [state, setState] = useState();

// 应该使用 URL 查询参数
const searchParams = useSearchParams();
const value = searchParams.get('key');
```
