### 2. ADR 模板定义 ✅

每个 ADR 包含：

- ✅ **编号**: ADR-000X
- ✅ **标题**: 简洁描述
- ✅ **状态**: Proposed / Accepted / Deprecated / Superseded
- ✅ **上下文**: 描述做出决策的背景
- ✅ **决策**: 描述实际采取的决策
- ✅ **权衡**: 描述考虑的替代方案及权衡
- ✅ **后果**: 描述决策的后果（正面/负面）
- ✅ **相关决策**: 关联的其他 ADR

#### v1.4.0 核心架构决策 (ADR-0006 ~ 0009)

**ADR-0006: Agent Scheduler 架构** ⭐

- ✅ 为什么使用能力评分而不是规则引擎
  - 规则引擎复杂度高、难以维护
  - 能力评分简单直观、灵活可调
- ✅ 为什么选择 Zustand 而非其他状态管理
  - 简洁 API、性能优化、TypeScript 支持
- ✅ 多 Agent 协作架构设计
  - 顺序协作、并行协作、评审协作
  - 自动触发和手动干预
- ✅ 完整的系统架构图和代码示例

**ADR-0007: 性能监控架构** ⭐

- ✅ 为什么选择 Z-score 异常检测
  - 简单高效、可解释性强
  - 自适应基准线学习
- ✅ 为什么不使用商业 APM 工具
  - 成本敏感（$100-500/月 vs $0）
  - 数据所有权和定制性
- ✅ 数据存储策略（Redis + PostgreSQL）
  - Redis: 实时指标、基准线、告警去重
  - PostgreSQL: 历史数据、异常记录、根因分析
- ✅ 根因分析自动化和性能预算控制

**ADR-0008: WebSocket 房间系统设计** ⭐

- ✅ 为什么选择房间而不是单一连接
  - 消息隔离、细粒度控制、高效广播
  - 多场景支持、易于扩展
- ✅ 权限模型设计决策
  - 5 种角色（owner, admin, moderator, member, guest）
  - 16 种权限（房间、消息、管理员）
  - 层级强制和权限授予/撤销
- ✅ 消息持久化策略
  - Map-based 内存存储（O(1) 访问）
  - 离线消息队列（TTL 7 天）
  - 消息编辑、删除、反应、置顶

**ADR-0009: React Compiler 采用策略** ⭐

- ✅ 为什么作为可选功能而不是默认启用
  - 兼容性风险可控
  - 渐进式迁移
  - 灵活回滚
- ✅ 兼容性检查策略
  - 自动检测不兼容的组件
  - 生成兼容性报告
  - 生成迁移指南和修复步骤
- ✅ 回滚机制设计
  - 环境变量开关
  - API 动态切换
  - A/B 测试
  - 零停机回滚

## 📝 ADR 内容亮点

### ADR-0006: Agent Scheduler 架构

**核心设计**:

- 能力评分算法（多维度综合评分）
- 权重配置（capability: 0.4, load: 0.3, performance: 0.2, response: 0.1）
- Zustand Store 设计（agents, tasks, decisions, actions）
- 多 Agent 协作流程（自动触发、手动干预）

**预期收益**:

- 调度效率提升 70-80%
- 任务完成时间减少 30-40%
- 主人干预需求减少 50%

### ADR-0007: 性能监控架构

**核心设计**:

- Z-score 异常检测（阈值 2: warning, 3: critical）
- 基准线自动学习（100 样本）
- 混合存储策略（Redis + PostgreSQL）
- 根因分析自动化（数据库、API、渲染、资源）

**预期收益**:

- 问题发现时间减少 60-90%（2-4h → 15-30min）
- 根因分析时间减少 70-80%（1-2h → 15-30min）
- 告警准确率提升 40%（~60% → >85%）
- 成本节约 $100-500/月（vs 商业 APM）

### ADR-0008: WebSocket 房间系统设计

**核心设计**:

- 6 种房间类型（task, project, chat, document, voice, video）
- 5 种角色（owner, admin, moderator, member, guest）
- 16 种权限（房间 7 + 消息 6 + 管理 3）
- 消息持久化（Map + 离线队列 + TTL）

**预期收益**:

- 连接稳定性从 95% 提升至 99%+
- 完整离线消息支持
- 细粒度权限控制，防止越权
- 多场景支持，易于扩展

### ADR-0009: React Compiler 采用策略

**核心设计**:

- 可选编译模式（环境变量控制）
- 白名单模式（只编译指定文件）
- 兼容性检查（自动扫描不兼容组件）
- 回滚机制（环境变量 + API + A/B 测试）

**预期收益**:

- 减少 20-40% 不必要的重新渲染
- UI 响应速度提升 15-25%
- 内存使用优化 10-15%
- 平滑迁移体验，风险可控
