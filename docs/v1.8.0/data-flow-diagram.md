## 5. 数据流关键路径

### 5.1 端到端延迟

```
用户点击执行
     │ 50ms
     ▼
API 接收请求
     │ 20ms
     ▼
WorkflowEngine 初始化
     │ 100ms
     ▼
NodeExecutor 执行
     │ 50ms
     ▼
MemorySystem 检索
     │ 30ms
     ▼
MessageRouter 路由
     │ 10ms
     ▼
Agent 接收消息
     │ 2000ms (实际任务执行时间)
     ▼
Agent 返回结果
     │ 10ms
     ▼
MessageRouter 返回
     │ 30ms
     ▼
MemorySystem 存储
     │ 20ms
     ▼
MetricsCollector 采集
     │ 10ms
     ▼
前端更新状态
     │
     ▼
总延迟: ~2340ms (不包括任务执行时间)
```

### 5.2 告警触发路径

```
异常发生
     │ 10ms
     ▼

     │ 5ms
     ▼
实时聚合
     │ 20ms
     ▼

     │ 50ms
     ▼
触发告警
     │ 100ms
     ▼
发送通知 (Slack)
     │ 200ms
     ▼
用户收到告警

总延迟: ~385ms
```
