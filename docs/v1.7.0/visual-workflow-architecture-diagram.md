## 2. 数据流图

### 2.1 工作流执行流程

```
用户点击"执行"
    │
    ▼
┌─────────────────┐
│ 前端调用 API    │ POST /api/instances

         │
         ▼
┌─────────────────┐

└────────┬────────┘

         ▼
┌─────────────────┐
│ WorkflowEngine │ 开始执行
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ 查找 Start 节点 │
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ NodeExecutor   │ 执行节点逻辑
└────────┬────────┘
         │
    ┌────┴────┐
    │         │
    ▼         ▼
Agent节点   条件节点
    │         │
    ▼         ▼
┌─────────┐  ┌─────────┐
│Agent     │  │条件判断  │
│Scheduler│  │表达式求值│
└────┬────┘  └────┬────┘
     │            │
     ▼            │

给Agent         │
     │            │
     ▼            │

     │            │
     └─────┬──────┘
           │
```
