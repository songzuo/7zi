## 7. 文档模板建议

### 7.1 标准文档模板

```markdown
---
title: 文档标题
description: 简短描述
lastUpdated: YYYY-MM-DD
version: x.y.z
owner: 负责角色
reviewers: [角色1, 角色2]
tags: [tag1, tag2]
---

# 标题

## 概述
[简要说明文档目的]

## 快速参考
[核心命令/代码片段]

## 详细内容
[分章节详细说明]

## 示例
[代码示例]

## 故障排查
[常见问题和解决方案]

## 相关文档
- [链接1]
- [链接2]

---

**最后更新**: YYYY-MM-DD
**版本**: x.y.z
**反馈**: [issue 链接]
```

### 7.2 API 端点模板

```markdown
## {HTTP_METHOD} {endpoint}

**功能**: 简要描述

**认证**: 需要/不需要

**请求参数**:
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|

**请求示例**:
```json
{}
```

**响应 (200)**:
```json
{}
```

**错误响应**:
| 状态码 | 说明 |
|--------|------|

**变更历史**:
- v1.2.0: [变更说明]
```

```markdown

## 8. 自动化文档生成建议

### 8.1 可自动化的文档

| 文档类型 | 自动化方式 | 工具 |
|----------|------------|------|
| **API 端点列表** | 从代码注释/OpenAPI 注解生成 | `swagger-jsdoc` + `swagger-ui` |
| **TypeScript 类型文档** | 从 `.d.ts` 文件提取 | `typedoc` |
| **组件文档** | 从 React 组件提取 | `react-styleguidist` / `storybook` |
| **变更日志 (CHANGELOG)** | 从 git commit message 生成 | `standard-changelog` |
| **测试覆盖率报告** | 从 CI 生成 | Vitest + GitHub Actions |
| **依赖审计报告** | 从 package.json 生成 | `npm audit` + 自动化脚本 |
| **部署清单** | 从 CI/CD 配置生成 | GitHub Actions artifacts |

### 8.2 建议的自动化流程

```
┌─────────────────┐
│  代码提交/合并   │
└────────┬────────┘
         ▼
┌─────────────────┐
│  CI/CD Pipeline │
├─────────────────┤
│ 1. 运行测试     │
│ 2. ESLint 检查  │
│ 3. TypeScript   │
│ 4. 生成覆盖率   │
│ 5. 生成 API 文档│
│ 6. 生成 changelog│
└────────┬────────┘
         ▼
┌─────────────────┐
│  自动发布       │
├─────────────────┤
│ 1. 更新版本号   │
│ 2. 发布 npm     │
│ 3. 创建 GitHub  │
│    Release      │
│ 4. 部署文档网站 │
└─────────────────┘
```

### 8.3 建议的工具链

| 工具 | 用途 |
|------|------|
| **VitePress** | 静态文档网站生成 |
| **docusaurus** | React 风格文档网站 |
| **swagger-ui** | API 文档交互式展示 |
| **typedoc** | TypeScript API 文档 |
| **storybook** | React 组件文档 + playground |
| **github-changelog-generator** | 自动生成 CHANGELOG |
| **renovate** | 依赖更新自动化 |

### 8.4 文档版本同步策略

```bash
# 建议：在 CI 中添加文档同步检查
scripts/
├── sync-docs-version.sh    # 同步所有文档版本号
├── generate-api-docs.js    # 从代码生成 API 文档
├── generate-changelog.sh   # 从 git 生成 changelog
└── validate-docs.sh        # 验证文档链接和格式
```
