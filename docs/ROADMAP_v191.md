# v1.9.1 技术路线图

**版本**: v1.9.1  
**创建日期**: 2026-04-03  
**基于版本**: v1.9.0 (AI 对话式任务创建)  
**目标发布**: 2026-04-15  

---

## 📋 执行摘要

v1.9.1 是 v1.9.0 的优化版本，核心目标是**完善 AI 对话式任务创建体验**、**清理技术债务**和**提升系统稳定性**。本版本不引入重大新功能，而是专注于打磨现有功能和解决遗留问题。

### 版本定位

| 维度 | v1.9.0 | v1.9.1 | 变化 |
|------|--------|--------|------|
| **核心功能** | AI 对话式任务创建 | 功能完善 + 稳定性 | 🔄 优化 |
| **类型安全** | 98 个错误待修复 | 目标 < 20 个 | ⬇️ -80% |
| **测试覆盖** | 96% | 目标 98%+ | ⬆️ +2% |
| **解析准确率** | 基础实现 | 目标 85%+ | ⬆️ 优化 |

---

## 🎯 v1.9.1 目标概述

### 主目标

1. **技术债务清理** - 解决 v1.9.0 遗留的类型问题和测试失败
2. **AI 解析增强** - 提升自然语言解析准确率和用户体验
3. **工作流模板** - 提供常用工作流模板，降低使用门槛

### 非目标

- ❌ 不引入新的核心功能模块
- ❌ 不进行大规模架构重构
- ❌ 不修改数据库 Schema

## 📊 功能需求列表

### P0 - 必做项 (阻塞发布)

#### P0-1: TypeScript 类型错误修复

**问题描述**: 当前项目存在 98 个 TypeScript 类型错误，影响开发体验和代码质量。

**影响范围**: 全项目

**解决方案**:
1. 启用部分严格模式选项
2. 修复 `lib/workflow/` 相关类型错误
3. 修复 `components/workflow/` 相关类型错误
4. 消除关键路径上的 `any` 类型

**工作量估算**: 15-20 小时

**验收标准**:
- [ ] TypeScript 编译错误 < 20 个
- [ ] `lib/workflow/` 模块 0 错误
- [ ] `components/workflow/` 模块 0 错误

---

#### P0-2: 测试失败修复

**问题描述**: v1.9.0 新增功能的测试覆盖不完整，部分现有测试失败。

**影响范围**: 测试套件

**解决方案**:
1. 修复 `TaskParser.test.ts` 测试用例
2. 补充 `TaskCreationChat` 组件测试
3. 补充 `QuickTaskModal` 组件测试
4. 修复集成测试中的 mock 问题

**工作量估算**: 10-15 小时

**验收标准**:
- [ ] 测试通过率 ≥ 99%
- [ ] `workflow/` 模块测试覆盖率 ≥ 90%
- [ ] 无 flaky 测试

---

#### P0-3: TaskParser 解析准确率优化

**问题描述**: 自然语言解析器的准确率不够高，复杂表达容易识别失败。

**影响范围**: `lib/workflow/TaskParser.ts`

**解决方案**:
1. 扩展关键词词典
2. 增加复合意图识别
3. 支持中英文混合输入
4. 添加错误恢复机制

**工作量估算**: 8-12 小时

**验收标准**:
- [ ] 常见意图识别准确率 ≥ 85%
- [ ] 支持中英文混合输入
- [ ] 未知意图返回改进建议

### P1 - 重要项 (优先完成)

#### P1-1: 工作流模板库

**问题描述**: 用户创建工作流时缺乏参考模板，学习成本高。

**影响范围**: `components/workflow/`

**解决方案**:
1. 创建 10+ 常用工作流模板
2. 模板分类：自动化、监控、通知、数据处理
3. 支持一键导入模板
4. 模板预览功能

**模板列表**:

| 模板名称 | 类型 | 用途 |
|---------|------|------|
| 每日报告自动化 | scheduled | 定时生成并发送报告 |
| 服务健康监控 | monitoring | 监控服务状态并发送告警 |
| 审批流程 | human_approval | 多级审批工作流 |
| 数据同步 | integration | 跨系统数据同步 |
| Webhook 处理 | webhook | 接收并处理 Webhook 事件 |

**工作量估算**: 12-16 小时

**验收标准**:
- [ ] 提供 10+ 预定义模板
- [ ] 支持模板一键导入
- [ ] 模板可编辑和保存

---

#### P1-3: API 响应格式统一

4. 完善错误消息

**工作量估算**: 6-8 小时

**验收标准**:
- [ ] 所有 workflow API 使用统一格式
- [ ] 错误响应包含错误码和详细信息
- [ ] 响应包含请求 ID

**验收标准**:
