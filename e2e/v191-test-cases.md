# v1.9.1 E2E 测试用例文档

## 测试概述

本文档定义了 v1.9.1 版本的端到端测试套件，覆盖关键用户流程、API 压力测试和前端集成测试。

## 测试环境

- **框架**: Playwright (E2E) + Vitest (单元测试)
- **浏览器**: Chromium (主), Mobile Chrome (响应式)
- **覆盖率目标**: 核心功能 80%+

## 5. 测试执行策略

### 5.1 CI/CD 集成

```yaml
# 测试执行流程
1. 单元测试 (每次提交)
   - 运行所有 *.test.ts 文件
   - 覆盖率检查 > 50%

2. E2E 测试 (每次 PR)
   - 运行关键路径测试 (P0)
   - 生成测试报告

3. 完整测试套件 (每次发布)
   - 运行所有 E2E 测试
   - 性能基准测试
   - 安全扫描
```

### 5.2 测试报告

- HTML 报告: `playwright-report/index.html`
- JUnit XML: `test-results/junit-results.xml`
- 覆盖率报告: `coverage/lcov-report/index.html`

## 附录

### A. 测试命令

```bash
# 运行所有单元测试
npm run test:run

# 运行覆盖率测试
npm run test:coverage

# 运行 E2E 测试
npm run test:e2e

# 运行 E2E 测试 (UI 模式)
npm run test:e2e:ui

# 运行所有测试
npm run test:all
```

### B. 测试文件命名规范

- 单元测试: `*.test.ts` 或 `*.spec.ts`
- E2E 测试: `e2e/*.spec.ts`
- 集成测试: `tests/integration/*.test.ts`
- API 测试: `tests/api/*.test.ts`
