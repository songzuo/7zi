FEATURES IMPLEMENTED
===============================================

1. ✅ USER SEARCH & PAGINATION
   - Endpoint: GET /api/users
   - Fuzzy search by name and email
   - Offset-based pagination (max 100 items)
   - Sort by: created_at, name, email, last_login_at
   - Filter by: status, role
   - Query params: search, status, role, page, limit, sort_by, sort_order

2. ✅ BULK USER OPERATIONS
   - Endpoint: POST /api/users/batch/bulk
   - Operations: enable, disable, delete
   - Maximum 100 users per operation
   - Detailed success/failure reporting
   - Audit logging for compliance

3. ✅ PROFILE IMAGE UPLOAD
   - Endpoint: POST /api/users/[userId]/avatar
   - Supported formats: JPG, PNG, GIF, WebP
   - Max file size: 5MB
   - Auto-resize to max 512x512 (stub)
   - Avatar removal: DELETE /api/users/[userId]/avatar
   - File validation (type and size)

4. ✅ RECENT ACTIVITY TRACKING
   - Endpoint: GET /api/users/[userId]/activity
   - Retrieve user's audit logs
   - Filter by action type (login, user_updated, etc.)
   - Filter by status (success, failed, pending)
   - Pagination support (limit, offset)
   - Human-readable action descriptions

5. ✅ USERPROFILE COMPONENT
   - Path: src/components/UserProfile/UserProfile.tsx
   - Display user profile information
   - Edit user name inline
   - Upload and preview avatar
   - Remove avatar
   - Client-side validation
   - Responsive design

===============================================
USAGE EXAMPLES
===============================================

1. LIST USERS WITH SEARCH AND PAGINATION:
   GET /api/users?search=john&status=active&page=1&limit=20

2. BULK ENABLE USERS:
   POST /api/users/batch/bulk
   {
     "userIds": ["user-1", "user-2"],
     "operation": "enable"
   }

3. UPLOAD AVATAR:
   POST /api/users/[userId]/avatar
   Content-Type: multipart/form-data
   avatar=@profile.jpg

4. GET USER ACTIVITY:
   GET /api/users/[userId]/activity?limit=20

5. USE USERPROFILE COMPONENT:
   import UserProfile from '@/components/UserProfile';
   <UserProfile userId="user-123" />
