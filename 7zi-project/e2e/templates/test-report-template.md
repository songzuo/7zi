## 附录: 命令参考

### 快速命令

```bash
# 运行所有测试
npm run test:e2e

# 运行特定模块
npx playwright test -g "Authentication"

# 运行失败测试
npx playwright test --grep-invert @skip

# 生成报告
npm run test:e2e:report

# 更新截图
npx playwright test --update-snapshots
```
