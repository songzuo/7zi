## 概述

Multi-Agent Orchestrator 是 7zi 项目的核心模块之一，提供多智能体协作编排能力。该模块支持：

- **并行执行** - 多个智能体同时处理任务
- **串行工作流** - 按依赖顺序执行任务链
- **动态分配** - 基于能力和负载智能分配任务
- **结果聚合** - 多种策略汇总智能体输出

## 核心组件

### 1. MultiAgentOrchestrator

主编排器类，负责：

- 任务分发和调度
- 智能体选择和负载均衡
- 结果收集和聚合

### 2. AgentRegistry

智能体注册表，提供：

- 智能体注册和发现
- 能力匹配查询
- 状态和负载管理

### 3. A2AProtocol

智能体间通信协议，支持：

- 消息传递
- 请求/响应模式
- 超时和重试机制

## 执行模式

### 并行执行 (Parallel)

适用场景：多个智能体独立处理同一任务

```typescript
const result = await orchestrator.executeParallel(agents, task)
```

特点：

- 高吞吐量
- 结果聚合
- 容错能力强

### 串行执行 (Sequential)

适用场景：有依赖关系的任务链

```typescript
const results = await orchestrator.executeSequential(workflow)
```

特点：

- 严格顺序保证
- 依赖检查
- 失败传播

### 动态分配 (Dynamic)

适用场景：根据智能体能力和负载自动分配

```typescript
const result = await orchestrator.assignDynamically(task)
```

特点：

- 自动负载均衡
- 能力匹配
- 最优分配

## 聚合策略

| 策略     | 描述               | 适用场景 |
| -------- | ------------------ | -------- |
| `first`  | 返回第一个成功结果 | 快速响应 |
| `all`    | 返回所有结果       | 数据收集 |
| `best`   | 返回最佳结果       | 质量优先 |
| `vote`   | 投票决定结果       | 共识决策 |
| `custom` | 自定义聚合         | 特殊需求 |

## 性能指标

- **任务分发延迟**: < 10ms
- **并行执行效率**: 可达串行的 N 倍（N = 智能体数量）
- **动态分配开销**: < 5ms

## 配置选项

```typescript
interface ExecutionOptions {
  timeout?: number // 超时时间（毫秒）
  maxAgents?: number // 最大智能体数量
  retryOnFailure?: boolean // 失败时重试
  maxRetries?: number // 最大重试次数
}
```
