## 📋 建议措施

### 紧急措施 (bot5.szspd.cn)

```bash
# 1. 立即为 bot5.szspd.cn 申请新证书
# 使用 certbot 申请 Let's Encrypt 证书
certbot certonly --nginx -d bot5.szspd.cn

# 2. 或使用 acme.sh
acme.sh --issue -d bot5.szspd.cn --nginx

# 3. 配置自动续期
certbot renew --dry-run
```

### 常规维护 (7zi.com)

```bash
# 检查自动续期状态
certbot certificates

# 手动续期测试
certbot renew --dry-run

# 配置 cron 自动续期
echo "0 0,12 * * * root certbot renew --quiet" >> /etc/crontab
```

### 最佳实践建议

1. **证书监控**
   - 配置证书到期提醒（建议提前 30 天）
   - 使用监控工具如 `certwatch` 或 Nagios 插件

2. **自动续期**
   - 确保所有 Let's Encrypt 证书配置自动续期
   - 定期测试续期流程

3. **TLS 配置**
   - 升级 Nginx/Apache 以支持 TLS 1.3
   - 禁用弱加密套件
   - 启用 HSTS

4. **证书链管理**
   - 确保中间证书正确配置
   - 使用 `fullchain.pem` 而非 `cert.pem`
