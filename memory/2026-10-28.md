   **在实现里一个字都没有** → 实现根本没有 production mode 分支（不判断 NODE_ENV）

   用 vi.spyOn(getDatabase) 自己制造失败

→ 这已是今天第 N 次同一类根因。**凡是断言 console.log / 具体日志文案的测试，
